# Uniswap v4 Hook Template

**A template for writing Uniswap v4 Hooks 🦄**

## Install

### Global libraries

```shell
forge install
```

### prb-math 

```shell
forge install PaulRBerg/prb-math@release-v4 --no-commit
```

## Test Contracts

### Compile

```shell
forge compile
```

### Test

```shell
forge test
```
